## What's new in 1.1.0

### Multiple models

- Added Qwen3.8-Flash-Next-FP8 support alongside DeepSeek-V4-Flash-0731.
- The server now reads a model catalog at startup and loads model weights only when a generation request needs them.
- The server keeps one model runtime loaded at a time. It closes the current runtime before it loads another model.
- The server can start with no installed model.

### Model names and API behavior

- Added fixed API model IDs and optional, case-sensitive aliases for both supported models.
- All generation endpoints accept an API model ID or Alias and return the requested name in responses and streaming events.
- `GET /v1/models` lists the API model IDs and aliases that were available when the server started.
- Removed `GET /api/settings` and `PUT /api/settings`. Both endpoints now return `404 not_found`.
- Fixed Codex Responses instruction, tool history, and tool argument conversion for Qwen.

### App

- Added a Model page for model downloads, verification, repair, DSpark, and per-model advanced settings.
- Moved Alias into each model's Advanced Settings view. Valid Alias changes are saved automatically.
- Added a Chat model picker. Changing the model keeps the current conversation.
- Assistant messages now keep the model name that was used for each request.
- Metric now shows the loading or loaded model. Metric history clears when the loaded model changes.

### Validation

- Swift: 58 passed, 3 skipped, and 0 failed.
- Python: 124 passed and 0 failed.
- Automated model lifecycle tests use fake runtimes. Full two-model memory switching measurements require both complete installed models and are not included in this release validation.
